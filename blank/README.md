# 공백 (BLANK) — Godot 4

웹 프로토타입(`../parry/`)으로 검증한 패링 특화 원히트 액션을 Godot 4.x(GDScript)로 다시 만드는 프로젝트. 시우 공방.

## 열기 / 실행
1. Godot **4.5 이상** (TileMapLayer 사용 → 최소 4.3, 4.5.1 에서 확인)으로 `blank/project.godot` 를 연다.
2. 처음 열면 에디터가 `art/`, `sounds/` 를 자동으로 임포트한다 (`.godot/` 캐시는 git 에 넣지 않음).
3. F5 (프로젝트 실행) → `scenes/Boot.tscn` ("시우 공방" 로고 2초 → 게임). `Main.tscn` 만 따로 실행(F6)해도 된다 (로고·스캔라인 없이 창 크기 그대로).

## 프로젝트 설정 (project.godot)
| 항목 | 값 |
|---|---|
| 게임 화면 | 480 × 270 (`Boot.tscn` 의 SubViewport) |
| 창 크기 | 1920 × 1080 (window override) |
| 확대 | 게임 화면을 창 안에 **정수 배율**로 키워 가운데 (Aspect keep, 남는 곳 검정) — `Boot.gd` 가 창 크기가 바뀔 때마다 계산 |
| Stretch | Mode = `disabled` (7단계에서 `viewport` → 바꿈, 아래 참고) |
| 텍스처 필터 | Nearest (프로젝트 기본 + SubViewport + 컨테이너) |
| 물리 틱 | 60, 렌더 프레임당 최대 1틱 (`max_physics_steps_per_frame = 1`, 아래 참고) |
| 픽셀 스냅 | 2D Transform / Vertex 모두 켬 |
| 렌더러 | Compatibility (2D 픽셀 게임에 충분, 저사양·웹 대응) |
| 배경색 | `#05060d` |

입력 맵 (Project Settings → Input Map 에서 바꿀 수 있음)

| 액션 | 키 |
|---|---|
| `move_left` / `move_right` | A / D (←/→) |
| `jump` | Space |
| `slash` | 마우스 왼쪽 |
| `restart` | R |
| `mute` | M |
| `menu` | ESC (옵션 메뉴) |

디버그 키 (`Debug.gd`): F1 반사 보정 표시 · F2 타격감 토글 패널 · F3 슬로우 10% · F4 프레임 진행 (F4 한 틱, Enter 해제) · F5 패링 타이밍 바 + 입력 오차 ms
· F6 다음 방으로 바로 · F7 지금 방 즉시 클리어 · F8 철견 페이즈 바꾸기 (1 → 2 → 3 → 결전) · F9 철견 무적 · F10 철견 패턴 강제 (① ~ ⑦ 차례로)
(F6 ~ F10, 철견 자세 숫자 · 패턴 이름, 왼쪽 아래 "1장 - 방 3/6" 표시는 디버그 빌드에서만 — 에디터 실행 · 디버그 내보내기)

- 방은 `Room.tscn` 의 `Terrain` 레이어에 에디터에서 직접 칠해서 고칠 수 있다. 타일 8px, 테스트 방 120 × 34 칸.
  웹 프로토타입 좌표를 8px 격자에 맞추느라 바닥 윗면은 238 → 240, 발판 A/C 는 190/188 → 192, B 는 146 → 144 로 몇 px 옮겼다
  (점프 최대 높이 55px 안에 모두 닿음).

### 3단계 확인
| 항목 | 결과 | 프로토타입 |
|---|---|---|
| 히트스톱 `hitstop(6)` | 정확히 6틱 월드 정지 후 time_scale 1.0 복귀 (언제 호출해도) | 같음 |
| 근접 적 | 추적 → 예고 25틱(0.4초) → 공격 → 플레이어 즉사 | 같음 |
| 플레이어 사망 | 사망음 + 히트스톱 4틱(0.06초) + "R — 재시작" | 같음 |
| 직접 베기 | 예고 시작 직후 베면 적 즉사 (휘두르기음 + 처치음) | 같음 |
| 근접 패링 | 예고 마지막 0.1초 안에 베면 패링음 + 히트스톱 6틱 + 적 즉사, 플레이어 생존 | 같음 |
| 히트스톱 중 클릭 | 멈춘 동안엔 안 베고, 풀리자마자 베기 | 같음 |
| 두 명 처치 | CLEAR + 클리어음 | 같음 |
| 효과음 | `time_return.wav` 길이 0.935초 읽음, `slowmo_loop` 반복 재생 설정, 합성음 휘두르기 0.16초·사망 0.4초·클리어 0.49초 | 같음 |

- **시간 처리**: 히트스톱·슬로우는 `Engine.time_scale`. time_scale 이 0 이어도 물리 틱은 실제 시간으로 계속 오고 delta 만 0
  (Godot 4.5.1 에서 확인) → 이때 게임 노드는 `TimeManager.frozen` 을 보고 입력만 모아 둔다. 실제 시간 연출은 `TimeManager.real_frames`.
- **효과음**: Godot 오디오는 time_scale 영향을 받지 않아 슬로우·히트스톱 중에도 실제 시간으로 재생. 페이드는 `Tween.set_ignore_time_scale`.
- `slowmo_loop.wav` 는 임포트 설정에서 Loop Mode = Forward.

## 1장 버티컬 슬라이스 — 2단계: 보스 "철견" (전면 개편)
하운드 제1 사냥개 부대장, 쌍권총 난사형. 패턴마다 요구하는 대응이 다르다 — 박자 패링, 근접 패링, 피하기, 방향 패링,
되치기, 소리로 패링, 핑퐁. 수치는 모두 `Config.boss`.

**자세 게이지 → 그로기 → 처형**
- 체력 칸 3개 아래 하늘색 자세 게이지 (`POSTURE_MAX` 100). 체력은 **처형으로만** 줄어듦 — 반사탄은 체력을 깎지 않음
- 오르는 양: 미니 패링 +10 · 풀 패링 반사 명중 +30 · 수류탄 되치기 폭발 +40 · 난타 1·2타 패링 +10, 3타 +25
- 3초 동안 패링이 없으면 초당 5씩 줄어듦 (`POSTURE_DECAY_DELAY` · `POSTURE_DECAY`)
- 100 → 그로기: 무릎 꿇고 2초 (`BOSS_STAGGER_TIME`), 머리 위에 흰 "처형" 깜빡임, 자세 게이지도 깜빡임
- 그로기 중 베면 처형: 체력 -1 · 히트스톱 12 · 흰 섬광 · 흔들림 8px · 빛줄기 · kill_sound 피치 0.8 · boss_armor 피치 0.7 · execute.wav · 장갑 금 +1
  → 포효 0.8초 (boss_intro 60% · 흔들림 4px) → 다음 페이즈. 2초 안에 못 베면 일어나고 자세 0
- 그로기가 아닐 때 칼로 베면 장갑에 막혀 '깡' (피해 없음)

**패턴**
| | 패턴 | 대응 |
|---|---|---|
| ① | 리듬 연사 2~4발 | 탄마다 원. 중간 탄 = 미니 패링 (parry_chang 1.2 · 70% · 히트스톱 4 · 장갑판 boss_armor), 마지막 탄 = 풀 패링 (기존 시퀀스 → 철견 명중, 자세 +30 · 움찔) |
| ② | 권총 난타 (80px 안) | 달려들어 손잡이로 3연타 — 1→2타 0.35초, 2→3타 0.8초 (팔을 크게 치켜들고 멈칫). 매 타격 0.3초 전 권총이 빨갛게 점멸. 근접 패링 = parry_chang + 히트스톱 6 + 자세 +10, 3타 패링 = 철견이 크게 튕겨남 + 자세 +25 |
| ③ | 발차기 (40px 안, 패링 불가) | 0.4초 예고 (다리 보라색) → 발차기 즉사 — 베어도 막히지 않음, 점프나 거리로 피함 → 0.5초 빈틈 |
| ④ | 도탄 사격 (페이즈 2~) | 옆 벽에 한 번 튕겨 오는 히트스캔. 조준선이 튕기는 점(작은 빨간 점)에서 꺾임. 원은 플레이어 몸 둘레 + 원 위 작은 화살표 = 날아오는 방향. **방향 패링**: 판정 창 안에서 그 방향 ±60° (`DIRECTIONAL_PARRY_ANGLE`)로 베어야 성공 → 풀 패링. 다른 방향 = 사망 (F5: "방향 틀림") |
| ⑤ | 수류탄 (페이즈 2~) | 포물선으로 던짐 (grenade_pin.wav), 1.2초 뒤 폭발 (반경 50, 즉사, explosion.wav). 빨간 불빛이 점점 빨리 깜빡이고, 바닥에 떨어지면 폭발 범위가 빨간 원으로. 베면 마우스 방향으로 되치기 (철견 쪽이면 조준 스냅) → 철견 근처 폭발 = 자세 +40 + 경직 1초. 되친 수류탄은 플레이어를 해치지 않음 |
| ⑥ | 섬광탄 (페이즈 3~) | 던지고 0.5초 뒤 화면이 2초 하얗게 (`FLASH_DURATION`) — 플레이어 · 철견의 희미한 실루엣만, 원 · 조준선 없음. 그동안 효과음은 먹먹하게 (World 버스 로우패스), gun_cock.wav 만 선명. 3발 — 각 발사 0.5초 전 "철컥" → 그 박자에 패링 (미니 패링 +10, 성공하면 화면이 1프레임 노랗게) |
| ⑦ | 핑퐁 결투 (결전) | 체력 1 의 마지막 처형을 권총으로 막아내고 "아직이다!" → 랠리: 철견 사격 → 패링 → 철견이 권총으로 되받아침 (parry_chang 0.9 + 장갑 불꽃) → … 원이 줄어드는 시간만 0.8 → 0.6 → 0.45 → 0.35초 (판정 창은 같음). 4번째 패링 = 풀 패링, 철견이 못 받아냄 → 최종 처치. 랠리 중 실패 = 사망 → 결전 시작부터 |

  ②③ 은 가까울 때만, ④ 는 튕길 벽이 보일 때만. 휴식 중 40px 안으로 붙으면 바로 발차기 (직전이 발차기면 난타)

- 등장 (이름 카드 · boss_intro · "등록도 안 된 놈이 칼을 들고 왔다고?")과 처치 뒤 연출은 그대로: 마지막 풀 패링 슬로우 유지 2배 →
  16프레임 킬 + 흔들림 1.5배 + 쌍권총이 날아감 → 1초 뒤 무전 "철견 처리 확인. ...공백, 너 방금 웃었어?" → 2초 뒤 출구 열림
- 효과음: 기존 gun_fire (철견 피치 0.85) · parry_chang · boss_armor · boss_intro · kill_sound · slowmo 3종.
  새 소리 pistol_whip · gun_cock · grenade_pin · explosion · flashbang · stagger · execute 는 `sounds/` 에 넣으면 바로 쓰이고, 없으면 무음

## 보스 "철견" 재제작 — 0단계: 효과음 등록
보스 효과음 2차 9종을 `sounds/` 에 넣고 `Audio` 에 등록 (앞 무음 제거 · 음량 정리된 파일 그대로).

| 파일 | 길이 | 가장 큰 소리 | 볼륨 (`Config.audio`) | 용도 |
|---|---|---|---|---|
| gun_cock | 0.25s | 0.07s | SFX_GUN_COCK 0.8 | 슬라이드 사격 예고 |
| quickdraw | 0.35s | 0.22s | SFX_QUICKDRAW 0.9 | 속사 권총 뽑기 |
| pistol_whip | 0.45s | 0.12s | SFX_WHIP 0.9 | 건카타 내려치기 |
| execute | 0.65s | 0 | SFX_EXECUTE 1.0 | 반격 베기 명중 |
| stagger | 0.50s | 0 | SFX_STAGGER 0.8 | 철견 휘청 |
| explosion | 0.60s | 0 | SFX_EXPLOSION 1.0 | 물탱크 폭발 |
| flashbang | 1.00s | 0 | SFX_FLASHBANG 0.9 | 조명 파괴 · 정전 |
| thunder | 0.90s | 0.17s | SFX_THUNDER 0.7 | 번개 |
| rain_loop | 4.00s | — | SFX_RAIN 0.35 | 보스방 빗소리 (이음새 없는 반복) |

- `Audio.play_synced(이름, 타격_월드시각)`: 피크 위치(`Audio.PEAKS`)만큼 일찍 재생해 그 지점이 타격 순간에 오게.
  소리는 실제 시간으로 재생되므로 남은 월드 시간을 지금 시간 속도로 나눠 비교 — 슬로우면 그만큼 늦게 시작, 히트스톱 중엔 기다림,
  이미 늦었으면 앞부분을 건너뛰고 재생. `cancel_synced` 로 취소
- `Audio.play_loop` / `set_loop_volume` / `stop_loop`: 반복 재생 (풀과 따로, 실제 시간 페이드). `stop_all`(재시작)이면 같이 멈춤
- 효과음은 시간 속도(슬로우 · 히트스톱)의 영향을 받지 않음 (Godot 오디오는 `Engine.time_scale` 과 무관)
- 아직 없는 dash_whoosh · slide · jump 는 넣으면 바로 쓰이고 없으면 무음 (볼륨 키 SFX_DASH · SFX_SLIDE · SFX_JUMP 0.8)

**들어 보기** — F2 패널: **B** 새 효과음 차례로 재생 (rain_loop 차례에서는 빗소리 반복 켜기/끄기),
**N** 싱크 테스트 — 0.6초 뒤 한 순간에 맞춰 quickdraw + gun_fire / pistol_whip + parry_chang (번갈아)
