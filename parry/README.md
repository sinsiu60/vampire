# PARRY (프로토타입) — 시우 공방

카타나 제로에서 영감을 받은 2D 사이드뷰 원히트 액션 플랫포머. 핵심 동사는 **받아친다(패링)** 하나.
순수 HTML5 Canvas + JavaScript, 이미지 파일 없음. 모든 그래픽과 효과음은 코드로 생성.

## 실행
`parry/index.html` 을 브라우저(Chrome/Edge/Firefox)로 열면 됩니다. 서버 불필요.
효과음 파일(`sounds/*.wav`)은 직접 열면 `<audio>` 요소로, 로컬 서버로 열면(예: `npx http-server parry`) Web Audio 로 더 정확하게 재생됩니다.

## 조작
| 입력 | 동작 |
|---|---|
| A / D | 좌우 이동 |
| Space | 점프 (누르는 시간만큼 높이, 코요테 타임·점프 버퍼 0.1초) |
| 마우스 좌클릭 | 마우스 방향으로 베기 + 짧은 돌진 |
| R | 즉시 재시작 |
| M | 효과음 음소거 |
| F1 | 반사 보정 디버그 표시 (스냅 범위 부채꼴, 선택될 대상) |
| ESC | 옵션 메뉴 (화면 흔들림 강도 0~150%, 기본 100%, 브라우저에 저장) |
| F2 | 타격감 요소 토글 패널 (패널이 열린 동안 1~9, 0 으로 하나씩, - 로 전부 켜기/끄기) |
| F3 | 슬로우 모드 (게임 속도 10%) — 킬 연출을 프레임 단위로 확인 |
| F4 | 일시정지 후 한 프레임씩 진행 (누를 때마다 1프레임, Enter 로 해제) |
| Z / X / C / V | (F2 패널이 열린 동안) 휘두르기 / 처치 / 패링 / 사격 소리 미리 듣기 |

## 규칙
- 플레이어와 적 모두 한 방에 죽음. 방의 적 4명(근접 2, 총잡이 2)을 전부 처치하면 CLEAR.
- **패링**: 베기 시작 후 0.12초 안에 빨간 공격/총알이 칼에 닿으면 성공.
  - 근접 공격 패링 → 적 즉사
  - 총알 패링 → 마우스 방향으로 반사, 반사 총알은 적을 즉사
- 보라색 공격은 패링 불가 (구조만 있음, `unparryableChance` 를 올리면 등장).
- 칼로 적 몸통을 직접 베어도 처치됨. `CONFIG.slash.directKill = false` 로 바꾸면 **패링으로만** 처치하는 모드.

## 패링 반사 보정 (Aim Assist) — `CONFIG.aimAssist`
강하게 돕지만 티 나지 않게. 플레이어는 "내가 겨눈 대로 쳤다"고 느낌.
- **조준 스냅**: 총알 패링 시 마우스 방향 ±35°, 300px 안의 적 중 각도 차가 가장 작은 적을 정확히 겨눠 반사. 벽에 가려진 적은 제외(레이캐스트). 후보가 없으면 마우스 방향 그대로.
- **쏜 적 우선**: 그 총알을 쏜 적이 ±50° 안에 있으면 최우선 (거리·시야 조건은 동일하게 적용).
- **약한 유도**: 반사 총알은 대상 쪽으로 초당 최대 90°까지만 회전, 대상이 죽으면 직진.
- **판정 확대**: 반사 총알의 적 피격 판정 1.8배 (그래픽은 그대로).
- **반사 직후 슬로우**: 아래 '총알 패링 성공 시퀀스'로 대체.
- **근접 패링 보정**: 근접 공격 패링 판정 거리 +20%.

| 키 | 기본값 |
|---|---|
| `AIM_SNAP_ANGLE` | 35 |
| `OWNER_PRIORITY_ANGLE` | 50 |
| `AIM_SNAP_RANGE` | 300 |
| `HOMING_TURN_RATE` | 90 |
| `REFLECT_HITBOX_SCALE` | 1.8 |
| `MELEE_PARRY_RANGE_BONUS` | 0.2 |

## 총알 패링 성공 시퀀스 — `CONFIG.parrySeq` (실제 시간 기준)
| 시각 | 일어나는 일 |
|---|---|
| 0초 | `parry_chang` + 히트스톱 6프레임 + 섬광 / `slowmo_in` 재생, 시간 속도 1.0 → 0.1 (0.15초) |
| 0.15초 | `slowmo_loop` 반복 재생 |
| 0.6초 (= 0.15 + `SLOWMO_HOLD` 0.45) | `time_return` 재생, `slowmo_in`·`slowmo_loop` 0.2초 페이드아웃, 시간 속도 0.1 → 1.0 (ease-in). 길이는 **time_return.wav 의 실제 길이를 읽어서** 사용 (현재 파일 0.935초) |
| 0.6초 + time_return 길이 | 반사탄 명중 → `kill_sound` + 16프레임 킬 연출 |

- 반사탄은 남은 게임 시간 동안 대상까지 거리를 나눠 날아가, time_return 이 끝나는 그 프레임에 대상 중심에 닿습니다 (그 전엔 다른 적과 부딪히지 않음).
- 스냅 대상이 없으면 슬로우 시퀀스는 그대로 재생되고 반사탄은 마우스 방향으로 자유 비행.
- 근접 패링은 슬로우 없이 `parry_chang` + 즉시 처치(`kill_sound` + 킬 연출).
- R 재시작·플레이어 사망 시 시퀀스 소리 정리 후 정상 속도. ESC 메뉴를 열면 소리도 일시정지.
- F3/F4 디버그 중에는 게임 프레임만 느려지고 소리는 실제 시간이라 둘이 어긋납니다 (정상 속도에선 맞음).

### 효과음 — `CONFIG.audio.samples`
| 파일 | 언제 | 볼륨 | 피치 |
|---|---|---|---|
| `gun_fire.wav` | 적 발사 순간 | `SFX_GUN` 0.8 | 0.95~1.05 랜덤 |
| `parry_chang.wav` | 패링 성공 | `SFX_PARRY` 1.0 | |
| `slowmo_in.wav` | 슬로우 진입 | `SFX_SLOWMO_IN` 0.8 | |
| `slowmo_loop.wav` | 슬로우 유지 (반복) | `SFX_SLOWMO_LOOP` 0.5 | |
| `time_return.wav` | 시간 복귀 | `SFX_TIME_RETURN` 1.0 | |
| `kill_sound.wav` | 모든 처치 | `SFX_KILL` 1.0 | 0.92~1.08 랜덤 |

모든 효과음은 슬로우모션과 무관하게 실제 시간으로 재생. 휘두르기·사망·클리어는 파일이 없어 합성음을 쓰고, 파일을 못 읽은 경우에만 사격/패링/처치도 합성음으로 대체합니다.

## 킬 연출 타임라인 — `CONFIG.kill` (60fps, 카타나 제로 실측 기준)
| 프레임 | 일어나는 일 |
|---|---|
| 0 | 처치. 타임스톱 시작 — 플레이어와 맞은 적은 베는 자세로 정지 (다른 적·총알도 정지, `FREEZE_OTHERS`) |
| 0~10 | **빛줄기**: 공격 방향으로 타격 지점을 지나는 2px 직선. 플레이어 뒤 화면 밖 → 적 너머 화면 밖. 머리가 먼저 빠르게, 꼬리가 따라오며 사라짐. 흰 중심 + 하늘색 테두리. 바닥 윗면을 지나는 지점에 흙먼지 |
| 0~4 | **3겹 궤적**이 휘둘러짐: 바깥 하늘색, 중간 분홍(1.5프레임 늦게), 중심 노랑. 타임스톱 동안 유지 |
| 0~15 | **피**: 빨간 덩어리 30~40개가 공격 방향 원뿔로 천천히 퍼짐. **흔들림**: 8px 에서 시작, 매 프레임 랜덤이되 공격 방향으로 치우침 |
| 16 | 해제: 적 두 조각이 공격 방향으로 날아감, 3겹 궤적 사라짐, 조작 재개. 피는 중력을 받아 떨어져 바닥·벽에 자국 |
| 16~21 | 흔들림 꼬리 → 21프레임에 0 (조작 가능한 시간엔 0.2px 이하) |

| 키 | 기본값 | 키 | 기본값 |
|---|---|---|---|
| `KILL_HITSTOP_FRAMES` | 16 | `BEAM_FRAMES` | 11 |
| `BEAM_WIDTH` | 2 | `TRAIL_PINK_LAG` | 1.5 |
| `BLOOD_MIN` / `BLOOD_MAX` | 30 / 40 | `BLOOD_STOP_SPEED` | 0.12 |
| `SHAKE_START` | 8 | `SHAKE_TAIL_FRAMES` | 6 |

색은 `CONFIG.colors` 의 `blood`, `beamCore`/`beamEdge`, `trailOuter`/`trailMid`/`trailCore`, `dust` (요청에 따라 원래 색 규칙의 예외).

## 타격감 — `CONFIG.juice`
처치/패링 순간 아래가 같은 프레임에 동시에 터집니다. F2 패널에서 하나씩 꺼 보며 무엇이 가장 큰지 비교할 수 있습니다.
1. **타임스톱/히트스톱**: 처치는 위 킬 연출 타임라인(16프레임), 패링 6프레임(`HITSTOP_PARRY_FRAMES`). 정지 중에도 흔들림·섬광은 재생.
2. **피격 흰 섬광**: 맞은 적 실루엣이 2프레임 동안 완전 흰색 (검은 1px 테두리로 흰 궤적 위에서도 보임).
3. **적 날아가기**: 두 조각이 공격 방향으로 400px/s(`KILL_KNOCKBACK`)로 튕겨 나가 회전하며 날아가고, 바닥에서 1~2번 튕긴 뒤 미끄러지다 멈춤.
4. **피 + 자국**: 킬 연출 타임라인 참고. 지형에 닿은 피는 재시작 전까지 자국으로 남음.
5. **베기 궤적**: 평소엔 크고 굵은 흰 반달 (3프레임 유지 후 소멸), 적을 베면 3겹 킬 궤적.
6. **화면 흔들림**: 처치는 킬 연출 타임라인, 패링은 공격 방향으로 밀었다가 되돌아옴 (10px, 0.15초). ESC 옵션 배율 적용.
7. **플레이어 반동**: 적을 벤 순간 반대 방향으로 살짝 밀림.
8. **사운드**: 사격·패링·슬로우·시간 복귀·처치는 `sounds/*.wav` (위 표). 휘두르기는 합성음 —
   잡음 필터가 650→2900→850Hz 로 휩쓸리는 짧은 바람 소리 '쉭' (0.16초, 매번 음높이 ±12%)
9. **화면 섬광(패링)**: 패링 시 한 프레임 흰 화면.
10. **빛줄기 + 흙먼지**: 킬 연출 타임라인 참고.

## 패링 성공 연출
1. 히트스톱 6프레임 2. 한 프레임 흰 섬광 3. 칼 끝 노란 충격파 링
4. 반사 총알 빨강→노랑 + 꼬리 궤적 5. 짧고 강한 화면 흔들림 6. 적이 두 조각으로 갈라지고 파편이 흩어짐

## 수치 조정
`game.js` 맨 위 `CONFIG` 객체에 모든 수치가 모여 있습니다.
- `player` 이동/점프, `slash` 베기·패링 창·돌진, `melee`/`gunner` 적 AI·예고 시간
- `bullet` 총알 속도, `parry` 판정 여유, `aimAssist` 반사 보정, `parrySeq` 패링 슬로우 시퀀스, `kill` 킬 연출, `audio.samples` 효과음 볼륨·피치, `juice` 타격감, `debug` 슬로우 배율, `fx` 링·섬광 등 연출, `anim` 기울기·늘이고 줄이기·잔상·머플러
- `colors` 색 규칙 (검정/남색 배경, 흰색 플레이어, 빨강 적 공격, 보라 패링 불가, 노랑/주황 패링, 하늘색 UI)

## 코드 구조 (`game.js` 한 파일)
CONFIG → 화면 확대/입력 → 방 정의·지형 충돌 → 파티클·충격파 링·시체 조각·효과음 → 총알 → 플레이어 → 적(근접/총잡이) → 게임 상태·전투 판정 → 배경·스캔라인 → 60fps 고정 루프

개발 단계별 커밋(1~6단계)이 git 히스토리에 나뉘어 있어, 각 단계를 체크아웃해 실행해 볼 수 있습니다.
