# PARRY (프로토타입) — 시우 공방

카타나 제로에서 영감을 받은 2D 사이드뷰 원히트 액션 플랫포머. 핵심 동사는 **받아친다(패링)** 하나.
순수 HTML5 Canvas + JavaScript, 이미지 파일 없음. 모든 그래픽과 효과음은 코드로 생성.

## 실행
`parry/index.html` 을 브라우저(Chrome/Edge/Firefox)로 열면 됩니다. 서버 불필요.

## 조작
| 입력 | 동작 |
|---|---|
| A / D | 좌우 이동 |
| Space | 점프 (누르는 시간만큼 높이, 코요테 타임·점프 버퍼 0.1초) |
| 마우스 좌클릭 | 마우스 방향으로 베기 + 짧은 돌진 |
| R | 즉시 재시작 |
| M | 효과음 음소거 |
| F1 | 반사 보정 디버그 표시 (스냅 범위 부채꼴, 선택될 대상) |
| F2 | 타격감 요소 토글 패널 (패널이 열린 동안 1~9 로 하나씩, 0 으로 전부 켜기/끄기) |

## 규칙
- 플레이어와 적 모두 한 방에 죽음. 방의 적 4명(근접 2, 총잡이 2)을 전부 처치하면 CLEAR.
- **패링**: 베기 시작 후 0.12초 안에 빨간 공격/총알이 칼에 닿으면 성공.
  - 근접 공격 패링 → 적 즉사
  - 총알 패링 → 마우스 방향으로 반사, 반사 총알은 적을 즉사
- 보라색 공격은 패링 불가 (구조만 있음, `unparryableChance` 를 올리면 등장).
- 칼로 적 몸통을 직접 베어도 처치됨. `CONFIG.slash.directKill = false` 로 바꾸면 **패링으로만** 처치하는 모드.

## 패링 반사 보정 (Aim Assist) — `CONFIG.aimAssist`
강하게 돕지만 티 나지 않게. 플레이어는 "내가 겨눈 대로 쳤다"고 느낌.
- **조준 스냅**: 총알 패링 시 마우스 방향 ±35°, 300px 안의 적 중 각도 차가 가장 작은 적을 정확히 겨눠 반사. 벽에 가려진 적은 제외(레이캐스트). 후보가 없으면 마우스 방향 그대로.
- **쏜 적 우선**: 그 총알을 쏜 적이 ±50° 안에 있으면 최우선 (거리·시야 조건은 동일하게 적용).
- **약한 유도**: 반사 총알은 대상 쪽으로 초당 최대 90°까지만 회전, 대상이 죽으면 직진.
- **판정 확대**: 반사 총알의 적 피격 판정 1.8배 (그래픽은 그대로).
- **반사 직후 슬로우**: 히트스톱이 끝난 직후 0.15초 동안 게임 속도 40%.
- **근접 패링 보정**: 근접 공격 패링 판정 거리 +20%.

| 키 | 기본값 |
|---|---|
| `AIM_SNAP_ANGLE` | 35 |
| `OWNER_PRIORITY_ANGLE` | 50 |
| `AIM_SNAP_RANGE` | 300 |
| `HOMING_TURN_RATE` | 90 |
| `REFLECT_HITBOX_SCALE` | 1.8 |
| `REFLECT_SLOW_DURATION` | 0.15 |
| `REFLECT_SLOW_SCALE` | 0.4 |
| `MELEE_PARRY_RANGE_BONUS` | 0.2 |

## 타격감 — `CONFIG.juice`
처치/패링 순간 아래가 같은 프레임에 동시에 터집니다. F2 패널에서 하나씩 꺼 보며 무엇이 가장 큰지 비교할 수 있습니다.
1. **히트스톱**: 처치 0.12초(`HITSTOP_KILL`), 패링 0.18초(`HITSTOP_PARRY`). 정지 중에도 흔들림·섬광은 재생.
2. **피격 흰 섬광**: 맞은 적 실루엣이 2프레임 동안 완전 흰색 (검은 1px 테두리로 흰 궤적 위에서도 보임).
3. **적 날아가기**: 두 조각이 공격 방향으로 400px/s(`KILL_KNOCKBACK`)로 튕겨 나가 회전하며 날아가고, 바닥에서 1~2번 튕긴 뒤 미끄러지다 멈춤.
4. **파편 + 자국**: 공격 방향 원뿔로 15~25개. 지형에 닿은 파편은 재시작 전까지 자국으로 남음.
   빨강은 '적 공격' 전용 색이라 파편은 적 실루엣과 같은 어두운 강철색(`colors.gore`)입니다.
5. **반달 베기 궤적**: 크고 굵은 흰 반달이 3프레임 꽉 찬 채로 보인 뒤 빠르게 사라짐. 적을 맞히면 1.2배 크고 밝게.
6. **방향성 흔들림**: 공격 방향으로 화면을 밀었다가 되돌아옴 (처치 6px, 패링 10px, 0.15초).
7. **플레이어 반동**: 적을 벤 순간 반대 방향으로 살짝 밀림.
8. **사운드**: 휘두르기 바람 소리, 처치 고음+저음 두 겹, 패링 금속 '챙' (Web Audio 합성).
9. **화면 섬광(패링)**: 패링 시 한 프레임 흰 화면.

## 패링 성공 연출
1. 히트스톱 0.18초 2. 한 프레임 흰 섬광 3. 칼 끝 노란 충격파 링
4. 반사 총알 빨강→노랑 + 꼬리 궤적 5. 짧고 강한 화면 흔들림 6. 적이 두 조각으로 갈라지고 파편이 흩어짐

## 수치 조정
`game.js` 맨 위 `CONFIG` 객체에 모든 수치가 모여 있습니다.
- `player` 이동/점프, `slash` 베기·패링 창·돌진, `melee`/`gunner` 적 AI·예고 시간
- `bullet` 총알 속도, `parry` 판정 여유, `aimAssist` 반사 보정, `juice` 타격감, `fx` 링·섬광 등 연출, `anim` 기울기·늘이고 줄이기·잔상·머플러
- `colors` 색 규칙 (검정/남색 배경, 흰색 플레이어, 빨강 적 공격, 보라 패링 불가, 노랑/주황 패링, 하늘색 UI)

## 코드 구조 (`game.js` 한 파일)
CONFIG → 화면 확대/입력 → 방 정의·지형 충돌 → 파티클·충격파 링·시체 조각·효과음 → 총알 → 플레이어 → 적(근접/총잡이) → 게임 상태·전투 판정 → 배경·스캔라인 → 60fps 고정 루프

개발 단계별 커밋(1~6단계)이 git 히스토리에 나뉘어 있어, 각 단계를 체크아웃해 실행해 볼 수 있습니다.
