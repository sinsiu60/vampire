# Shadow Edge (가제)

2D 사이드뷰 핵앤슬래시 (DMC + 데드셀 느낌). 순수 HTML + JavaScript(Canvas), 외부 라이브러리 없음.

## 실행
`slash/index.html` 을 브라우저(Chrome/Edge/Firefox)로 열면 바로 실행. 서버 불필요.

## 진행 상황
- [x] 1단계: 이동 + 지상 콤보 + 근접 잡몹 + 타격감 (도형 임시 그래픽)
- [x] 2단계: 공중 콤보 (런처, 공중 3타, 내려찍기)
- [x] 3단계: 실루엣 그래픽 + 애니메이션 + 이펙트
- [x] 4단계: 패링 + 적 6종
- [x] 5단계: 스타일 랭크
- [ ] 6단계: 던전 방 구조 + 미니맵
- [ ] 7단계: 보스
- [ ] 8단계: 무기 3종 + 스킬 + 루팅·인벤토리
- [ ] 9단계: 로고 인트로, 타이틀, UI, 사운드
- [ ] 10단계: 층별 테마·보스, 밸런스

## 검극 (세키로식 패링)
- **판정**: 게임 시간(ms) 기준. 키 입력은 keydown 이벤트 시각으로 기록 → 프레임 오차 없음. 히트스톱 중엔 멈추고 슬로모션 중엔 같이 느려짐
  - F 누른 순간부터 0.18초 패링 활성 / 맞은 뒤 0.07초 안에 누르면 늦은 입력 보정(데미지는 그동안 보류) / 계속 누르면 가드 / 실패 시 0.25초 재입력 금지
  - 적 공격은 예고 시작 → 타격까지 공격마다 고정 시간(`telegraphMs`), 타격 직전 "슉" 소리, 칼이 닿는 모습 = 실제 타격 순간
- **예고 색**: 빨강 = 패링·가드 불가(회피) / 노랑 = 패링·가드 가능 / 흰색 섬광 = 간파 공격(보스 전용, 퍼펙트 패링 시 체간 대폭 증가)
- **체간**: 적 머리 위 바. 퍼펙트 패링·공격으로 차오르고 가만두면 회복. 가득 차면 무릎 꿇고 2초간 비틀거림 → 처형 가능
- **내 체간**: 화면 아래 가운데. 가드로 받으면 차오르고, 가득 차면 1초 경직
- **연속 패링 체인**: 1~2회 흰 불꽃 / 3~4회 노란 불꽃 + 줌인 / 5회 이상 주황 폭발 + 배경 어두워짐 + 체간 2배. 피격 시 리셋
- 모든 수치는 `config.js` 의 `parry`, `posture`, `execution`, `moves.COUNTER*`

## 스타일 랭크
- 오른쪽 위: D → C → B → A → S → SS → SSS + 게이지, 오를 때 글자가 튐
- 다양한 기술을 섞을수록 많이 오르고 같은 기술 반복은 덜 오름 (최근 7개 기술 기준)
- 보너스: 공중 콤보 ×1.35, 퍼펙트 패링(체인일수록 더), 회피 직후 반격, 체간 붕괴, 처형(대폭 + 최소 1랭크 상승)
- 피격 시 2랭크 하락, 가만히 있으면 서서히 하락 (높은 랭크일수록 빠르게)
- 방(현재는 웨이브) 클리어 시 최고 랭크에 따라 보상 (지금은 체력 회복, 8단계에서 아이템)
- 수치는 `config.js` 의 `style`

## 파일 구조 (`slash/js/`)
- `config.js` — **조작키(KEYBINDS)** 와 **모든 밸런스 수치** (이동, 점프, 대시, 스태미나, 기술 프레임·데미지·히트박스, 적 능력치, 타격감)
- `main.js` — 60fps 고정 타임스텝 루프, 히트스톱, 카메라, 게임 상태
- `input.js` — 키보드·마우스 입력 (스텝 단위 pressed/released, 우클릭 메뉴 차단)
- `player.js` — 플레이어 상태머신 (이동/점프/대시/콤보/차지/피격)
- `enemy.js` — 적 6종 AI (예고 → 공격 → 후딜, 경직·넉백, 그로기, 방패/부유/슈퍼아머)
- `projectile.js` — 적 투사체 (베기·패링으로 반사)
- `combat.js` — 히트박스 판정, 데미지·크리티컬·넉백·히트스톱, 패링·칼 부딪힘·방패 막기
- `style.js` — 스타일 랭크 점수·다양성·보너스·하락
- `effects.js` — 파티클, 베기 궤적, 대시 잔상, 데미지 숫자, 화면 흔들림, 임팩트 프레임
- `anim.js` — 관절 막대 인형 골격, 포즈 라이브러리·키프레임 보간, 팔 IK, 실루엣 그리기
- `render.js` — 층별 테마 배경(하늘 + 원경 3겹 패럴랙스 + 떠다니는 먼지), 지형, 캐릭터 그리기
- `dungeon.js` — 지형과 충돌 (현재는 연습 아레나)
- `ui.js` — HUD, 일시정지/게임오버 화면
- `audio.js` — Web Audio API 효과음 합성
