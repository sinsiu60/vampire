# Shadow Edge (가제)

2D 사이드뷰 핵앤슬래시 (DMC + 데드셀 느낌). 순수 HTML + JavaScript(Canvas), 외부 라이브러리 없음.

## 실행
`slash/index.html` 을 브라우저(Chrome/Edge/Firefox)로 열면 바로 실행. 서버 불필요.
첫 화면에서 클릭하거나 아무 키나 누르면 (브라우저가 소리를 허용) → "시우 공방" 로고 → 타이틀.

## 화면 흐름 (9단계)
- **로고**: 검은 화면을 청록 일섬이 가르고 그 틈에서 "시우 공방" 이 열림 (아무 키나 누르면 건너뜀)
- **타이틀**: 시작하기 (3층 던전) / 콤보 연습장 / 조작법 / 설정. 키보드(W/S·↑↓ + Enter/스페이스) 또는 마우스
- **일시정지 (Esc)**: 계속하기 / 다시 시작 / 조작법 / 설정 / 타이틀로
- **게임오버 · 던전 클리어**: 도달 층, 플레이 시간, 처치, 최대 히트, 최고 스타일 랭크 + 다시 시작 / 타이틀로 (게임오버에서 Enter = 바로 다시 시작)
- **설정**: 효과음 · 음악 볼륨, 화면 흔들림 켜기/끄기 (브라우저에 저장)
- **조작법**: 키 배치(KEYBINDS 를 따라 자동으로 바뀜), 예고 색, 무기별 스킬
- 게임 중 아래쪽 긴 도움말은 없앰 → 시작할 때 잠깐 안내만, F1 로 켜고 끔. 기술 이름 표시는 H(히트박스 디버그) 때만

## 콤보 연습장
- 허수아비 3개만 있는 아레나. 허수아비는 움직이지 않고, 띄우기·저글링·내려찍기·체간 붕괴·처형 다 됨
- 3초 동안 안 맞으면 체력·체간이 다시 차고, 쓰러지면 1.5초 뒤 다시 섬
- 위쪽: 이번 콤보 데미지 / 최고 기록 (히트 수) / DPS (최근 3초)
- **P**: 허수아비 공격 켜기/끄기 — 가까이 가면 노랑 베기 (패링 연습) / **O**: 허수아비 되살리기 + 기록 초기화
- 수치는 `config.js` 의 `practice`, `enemies.dummy`

## 사운드
- 효과음·음악 모두 Web Audio API 로 직접 합성 (파일 없음)
- 음악: 16분음표 스텝 시퀀서 — 타이틀(느린 아르페지오) / 던전(베이스 + 드럼) / 보스(빠르고 강하게, 보스가 나오면 자동 전환)
- 메뉴 이동·선택·뒤로, 로고 일섬·울림, 게임 시작, 게임오버, 던전 클리어 효과음 추가
- 곡 데이터·볼륨은 `config.js` 의 `audio`

## 런 구조 (로그라이크 1단계)
- 5층. 층마다 시작방 → 갈림길 → … → 보스방 (지나가는 방 7~9개). 방을 클리어하면 **오른쪽 끝에 다음 방 문 2~3개**가 열리고, 문 위 아이콘을 보고 골라서 **W(위)** 로 들어간다. 되돌아갈 수 없음
- **M**: 층 지도 (지나온 길, 지금 방, 다음 선택지, 보스까지 남은 갈림길)
- 방 종류 (data/rooms.js)

| 방 | 내용 | 지금 상태 |
|---|---|---|
| 전투 | 일반 적 웨이브 | ✔ |
| 엘리트 | 정예 + 호위 | ✔ (각인 보상은 2단계) |
| 저주 제단 | 저주 각인 / 공용 변형 | 제단만 (3·8단계) |
| 휴식 | 체력 40% 회복 / 각인 강화 | 회복 ✔ (강화는 2단계) |
| 상점 | 각인 판매 · 회복 · 리롤 | 회복약 ✔ (각인은 4단계) |
| 대장간 | 변형 구매 · 교체 | 모루만 (5·8단계) |
| 보스 | 층 끝, 다음 층 계단 | ✔ (4·5층은 임시로 기존 보스 강화판, 9단계에서 5종) |
- 지도 보장: 첫 갈림길은 전투만, 보스 직전은 휴식·상점 위주, 층마다 엘리트 1개 이상 + 상점·휴식·대장간 중 2종 이상
- **골드**: 적 처치 시 동전 (체력 비례, 정예 ×3, 보스 고정), 방 클리어 시 최고 스타일 랭크 보너스. 가까이 가면 빨려 들어옴. 방을 나갈 때 남은 동전은 자동으로 주움. HUD 왼쪽 위
- 장비 아이템(무기·갑옷·반지 드랍)과 보상 상자는 런에서 빠짐 → 각인·변형으로 대체될 예정 (Tab 인벤토리는 2단계에서 새로 만듦)
- 4·5층 테마 추가: 서리 묘역 / 공허의 첨탑

## 데이터 폴더 (`slash/data/`)
적·보스·층·방 데이터 (이후 각인·변형도 여기). 각 파일은 `DATA.이름 = { … }` 한 줄로 감싼 **순수 JSON** — 브라우저가 `file://` 에서 `.json` 파일을 읽지 못해서 서버 없이 실행되게 하려고 이렇게 했다. `=` 뒤 내용은 그대로 JSON 이라 복사해서 검사기에 넣어도 된다. 필드 설명은 각 파일 맨 위 주석
- `enemies.js` 적 / `bosses.js` 보스·패턴 / `floors.js` 층 (적 구성·배율·함정·보스·음악·방 가중치) / `rooms.js` 방 종류
- 새 파일을 만들면 `index.html` 에 `<script src="data/….js">` 를 `config.js` 보다 위에 추가

## 무기 3종 · 스왑 (계속 바꿔 쓸수록 유리)
세 무기를 모두 들고 다니며 R / 휠로 바꿔 쓴다 (스왑 자체 쿨 0.4초). 왼쪽 아래에 무기 3개 + 각 무기의 Q·E 쿨타임.

| 무기 | 성격 | Q | E | 전환기 (콤보 도중 스왑) | 약점 상대 |
|---|---|---|---|---|---|
| 검 | 균형, 패링 특화 | **간파 자세** (6초): 2초간 들어오는 공격 자동 퍼펙트 패링 (빨강 근접 공격도) | **발도 일섬** (10초): 앞으로 순간이동, 지나간 적들이 잠시 뒤 한꺼번에 베임 | 칼 뽑으며 원형 베기 | 원거리형 |
| 대검 | 느림, 체간 파괴 | **철벽** (8초): 3초 슈퍼아머, 받는 데미지 절반 + 주변에 반격 | **대지 분쇄** (12초): 차지 내려찍기, 체간 대폭 + 방패 파괴 | 내려찍기 + 충격파 (공중: 낙하 쪼개기) | 방패병 · 중갑병 |
| 건틀릿 | 빠름, 공중 특화 | **승룡권** (5초): 주변 적 전부 띄우고 같이 떠오름 | **유성 낙하** (9초): (지상이면 뛰어올라) 급강하 연타 → 착지 폭발 | 돌진 펀치 (공중: 공중 연타) | 비행형 |

- **칼집 회복**: 들고 있지 않은 무기의 스킬 쿨타임은 2배 속도로 줄어든다
- **스왑 어택**: 공격·스킬·공중 콤보 도중 스왑하면 새 무기의 전환기가 바로 나감 (히트 수·공중 저글링 그대로 이어짐)
- **공명**: 스왑 직후 3초간. 공격력 +25% / 다음 스킬 쿨타임 -30%. 공명 중 다시 스왑하면 단계 상승 (Ⅱ: +40%·-40%, Ⅲ: +60%·-50%)
  - 단, 지난 스왑 이후 적을 한 번 이상 맞혀야 단계가 오름 (R 연타만으로는 안 오름, `swap.resonance.requireHit` 로 끌 수 있음)
  - 무기에 청록 글로우 (단계가 높을수록 밝게), 왼쪽 아래 아이콘 테두리도 빛남
- **적 상성**: 약점 무기로 때리면 데미지·체간 +50%, 타격 멈춤·불꽃 강화, 방패도 못 막음. 적 머리 위에 약점 무기 아이콘 (지금 든 무기가 약점이면 밝게)
  - 보스는 페이즈마다 약점이 바뀜 (황혼의 검귀: 건틀릿 → 검 / 월야의 창기사: 대검 → 건틀릿 / 불꽃 성주: 검 → 대검), 보스 체력바 오른쪽에 표시
- **스타일 보너스**: 스왑 어택 적중 / 공명 Ⅲ 도달 / 한 콤보에 무기 3개 모두 맞힘(TRINITY)
- 검기 색: 검 청록 / 대검 주황 / 건틀릿 보라. 대검 차지 Lv3 · 건틀릿 공중 5타 등 기본 기술표는 무기마다 다름
- 수치는 `config.js` 의 `weapons.<무기>` (기술표 · skills · swapIn · strongVs), `swap` (쿨 · 칼집 회복 · 공명), `weakness`, `bosses.*.weakness`

## 장비 · 루팅
- 드랍: 일반 적 처치 시 확률(층별 10~14%), 보상 상자 1개 (방 최고 랭크가 높을수록 좋은 등급, 보스방 상자는 영웅 이상), 보스 격파 시 영웅 이상 2개
- 바닥 아이템은 **등급 색 빛기둥** (일반 흰색 / 희귀 파랑 / 영웅 보라 / 전설 주황, 높은 등급일수록 높고 진함). 가까이 가면 이름, 닿으면 자동으로 주움 (빈 장비 칸이면 바로 장착). 방을 나가도 그 방에 남음
- 장비 칸: 검 / 대검 / 건틀릿 (각 칸은 같은 종류 무기로만 교체) / 갑옷 (최대 체력 + 받는 피해 감소) / 반지 (치명타 확률). 무기는 등급이 높을수록 그 무기를 들었을 때 공격력 배율 ↑
- 랜덤 옵션 1~4개 (등급별): 공격력% / 공격 속도% (선딜·후딜 단축) / 치명타 확률 / 흡혈 / 스킬 쿨타임 감소 / 최대 스태미나 / 최대 체력 / 체간 피해%
- 전설 고유 효과: 뇌신(3번째 타격마다 번개) / 폭염(퍼펙트 패링 시 주변 폭발) / 피의 갈망(처치 시 회복) / 그림자(대시로 통과한 적에게 피해) / 광란(S 랭크 이상 공격력 +25%)
- **인벤토리 (Tab)**: 마우스로 가리키면 툴팁 + 지금 장착한 것과 비교 (바뀌는 능력치 초록 ↑ / 빨강 ↓). 클릭 = 장착·해제, X 두 번 = 버리기. 키보드로도 가능 (WASD + 스페이스). 무기별 스킬과 쿨타임도 표시
- 시작 장비: 검 · 대검 · 건틀릿 (일반 등급)
- 수치는 `config.js` 의 `loot`

## 검극 (세키로식 패링)
- **판정**: 게임 시간(ms) 기준. 키 입력은 keydown 이벤트 시각으로 기록 → 프레임 오차 없음. 히트스톱 중엔 멈추고 슬로모션 중엔 같이 느려짐
  - F 누른 순간부터 0.18초 패링 활성 / 맞은 뒤 0.07초 안에 누르면 늦은 입력 보정(데미지는 그동안 보류) / 계속 누르면 가드 / 실패 시 0.25초 재입력 금지
  - 적 공격은 예고 시작 → 타격까지 공격마다 고정 시간(`telegraphMs`), 타격 직전 "슉" 소리, 칼이 닿는 모습 = 실제 타격 순간
- **예고 색**: 빨강 = 패링·가드 불가(회피) / 노랑 = 패링·가드 가능 / 흰색 섬광 = 간파 공격(보스 전용, 퍼펙트 패링 시 체간 대폭 증가)
- **체간**: 적 머리 위 바. 퍼펙트 패링·공격으로 차오르고 가만두면 회복. 가득 차면 무릎 꿇고 2초간 비틀거림 → 처형 가능
- **내 체간**: 화면 아래 가운데. 가드로 받으면 차오르고, 가득 차면 1초 경직
- **연속 패링 체인**: 1~2회 흰 불꽃 / 3~4회 노란 불꽃 + 줌인 / 5회 이상 주황 폭발 + 배경 어두워짐 + 체간 2배. 피격 시 리셋
- 모든 수치는 `config.js` 의 `parry`, `posture`, `execution`, `moves.COUNTER*`

## 층별 특색 (10단계)
| 층 | 이름 | 테마 · 보스 | 적 배율 (체력/데미지) | 정예 | 함정 | 모닥불 |
|---|---|---|---|---|---|---|
| 1 | 노을의 성벽 | 노을 · 황혼의 검귀 | ×1 / ×1 | 없음 | 없음 | 없음 |
| 2 | 달빛 회랑 | 달밤 · 월야의 창기사 | ×1.3 / ×1.15 | 12% | 가시 함정 1~2개 | 체력 50% |
| 3 | 불타는 왕좌 | 불타는 성 · 불꽃 성주 | ×1.6 / ×1.3 | 20% | 화염 분출구 1~3개 | 체력 50% |
- **함정**: 대기 → 빨간 예고 → 작동. 패링 불가 (대시 무적으로 통과 가능). 적도 맞으니 밀어 넣거나 띄워 올리면 TRAP KILL 보너스. 방을 클리어하면 멈춤
- **정예**: 층 색으로 빛나는 큰 적 (체력 ×1.8, 데미지 ×1.3, 체간 ×1.6). 처치하면 희귀 이상 장비 확정 + ELITE 보너스
- **모닥불**: 2·3층 시작방. 위 키로 한 번 쉬어 체력 회복
- **층별 음악**: 던전·보스 곡이 층마다 다름 (2층 달밤은 어둡게, 3층은 빠르고 거칠게)
- 수치는 `config.js` 의 `floors`, `elite`, `traps`

## 밸런스 조정 (10단계)
자동 전투 봇으로 던전을 처음부터 끝까지 반복 플레이해 시간·받은 피해·피해 출처·보스에게 준 피해 비율을 재고 조정했다.
- **버그 수정**: 공중 공격을 계속 이어가면 중력이 줄어든 채로 끝없이 위로 올라가던 문제 → 체공은 정점 부근/내려올 때만, 적을 못 맞히면 점프당 3번까지만 (`air.floatRiseVy`, `freeSwings`, `floatHitWindow`)
- **버그 수정**: 보스 바닥 폭발과 철벽 반격이 동시에 일어나면 멈추던 문제
- **전환기 쿨타임 1초** (`swap.attackCooldown`): R 연타로 전환기만 계속 쓰는 게 보스 피해의 34% 를 차지 → 15% 로. 무기 교체 자체는 그대로 0.4초
- **보스 체력** 900/1100/1300 → 1600/2000/2400 (봇 기준 20초 → 30초, 사람은 더 김)
- 대검 전환기 데미지 30 → 26 (충격파 18 → 14)
- 낭떠러지 데미지 12 → 8, 상자 회복 배율 0.5 → 0.6


- 3층, 층마다 방 5~6개 (시작방 → 전투방 → 보스방). 매번 무작위 생성, 층마다 배경 테마가 바뀜
- 전투방에 들어가면 양쪽 문이 철창으로 잠기고, 적 웨이브(넓은 방은 2번)를 전멸시키면 열림
- 클리어하면 보상 상자 (그 방 최고 스타일 랭크가 높을수록 좋은 등급의 장비 + 체력 조금)
- 지형: 평지 / 높은 지대 / 낭떠러지 / 통과 발판. 높은 곳은 디딤 발판이 자동 배치
- 낭떠러지에 떨어지면 데미지 + 직전에 서 있던 발판으로 복귀. 적을 넉백으로 떨어뜨리면 처치(RING OUT)
- 보스방 클리어 후 오른쪽 문 → 다음 층, 3층 보스 격파 시 던전 클리어
- 왼쪽 위 미니맵: 현재 방(흰색) / 클리어(회청) / 전투 중(빨강) / 아직 모르는 방(점선) / 보스방 / 안 연 상자
- 수치는 `config.js` 의 `dungeon`

## 보스 (층마다 다름)
| 층 | 보스 | 무기 | 2페이즈 추가 패턴 |
|---|---|---|---|
| 1 | 황혼의 검귀 | 대검 | 난무: 노랑 → 노랑 → 흰색 섬광 찌르기 (리듬 패링) |
| 2 | 월야의 창기사 | 창 | 연속 내려찍기 3회 |
| 3 | 불꽃 성주 | 불꽃 대검 | 화염 기둥: 폭발이 보스 앞에서부터 번져감 |
- 공통 패턴: 돌진베기(노랑) / 점프 내려찍기(빨강, 착지 지점 표시 → 점프로 회피) / 검기 3연발(노랑, 낮게=점프 · 높게=가만히 · 가운데, 패링하면 반사) / 광역 경고 후 폭발(빨강, 바닥의 붉은 원)
- 체력 50% 이하: 포효(밀쳐냄) → 2페이즈: 예고·동작 1.3배 빨라짐 + 추가 패턴, 분노 기운
- 그로기 게이지(= 체간): 주로 퍼펙트 패링으로 차오름 (일반 공격은 35%만). 다 차면 쓰러져 3.7초간 무방비 → 런처로 띄워 공중 콤보 / 처형(최대 체력 30% 데미지, 마지막이면 두 동강)
- 화면 아래 큰 체력바 + 이름 + 2페이즈 경계 + 그로기 게이지, 등장 시 이름 연출
- 수치는 `config.js` 의 `bossPatterns`, `bosses`, `boss`

## 스타일 랭크
- 오른쪽 위: D → C → B → A → S → SS → SSS + 게이지, 오를 때 글자가 튐
- 다양한 기술을 섞을수록 많이 오르고 같은 기술 반복은 덜 오름 (최근 7개 기술 기준)
- 보너스: 공중 콤보 ×1.35, 퍼펙트 패링(체인일수록 더), 회피 직후 반격, 체간 붕괴, 처형(대폭 + 최소 1랭크 상승)
- 피격 시 2랭크 하락, 가만히 있으면 서서히 하락 (높은 랭크일수록 빠르게)
- 방 클리어 시 최고 랭크에 따라 보상 상자 등급 ↑ (연습장은 체력 회복)
- 수치는 `config.js` 의 `style`

## 파일 구조 (`slash/js/`)
- `config.js` — **조작키(KEYBINDS)** 와 **모든 밸런스 수치** (이동, 점프, 대시, 스태미나, 기술 프레임·데미지·히트박스, 적 능력치, 타격감)
- `main.js` — 60fps 고정 타임스텝 루프, 히트스톱, 카메라, 게임 상태
- `input.js` — 키보드·마우스 입력 (스텝 단위 pressed/released, 우클릭 메뉴 차단)
- `player.js` — 플레이어 상태머신 (이동/점프/대시/콤보/차지/피격), 무기 3종 스왑·전환기·공명, 무기별 스킬, 장비 능력치
- `loot.js` — 아이템 생성 (등급·랜덤 옵션·전설 효과), 장비 → 능력치, 바닥 드랍 빛기둥·줍기
- `skills.js` — 지면 충격파, 발도 일섬, 철벽 반격, 번개·폭발·대시 피해 (전설 효과)
- `inventory.js` — 인벤토리 화면 (장비 칸·가방·능력치·비교 툴팁)
- `boss.js` — 보스 3종: 패턴, 2페이즈, 그로기, 바닥 경고·폭발, 격파 연출
- `enemy.js` — 적 6종 AI (예고 → 공격 → 후딜, 경직·넉백, 그로기, 방패/부유/슈퍼아머)
- `projectile.js` — 적 투사체 (베기·패링으로 반사)
- `combat.js` — 히트박스 판정, 데미지·크리티컬·넉백·히트스톱, 패링·칼 부딪힘·방패 막기
- `style.js` — 스타일 랭크 점수·다양성·보너스·하락
- `effects.js` — 파티클, 베기 궤적, 대시 잔상, 데미지 숫자, 화면 흔들림, 임팩트 프레임
- `anim.js` — 관절 막대 인형 골격, 포즈 라이브러리·키프레임 보간, 팔 IK, 실루엣 그리기
- `render.js` — 층별 테마 배경(하늘 + 원경 3겹 패럴랙스 + 떠다니는 먼지), 지형, 캐릭터 그리기
- `dungeon.js` — 던전 생성 (층/방/지형/낭떠러지/문·철창/소환 위치/함정·모닥불 배치), 충돌 처리, 연습 아레나
- `traps.js` — 층별 함정 (가시 / 화염 분출구)
- `ui.js` — HUD (체력·스태미나·무기·스킬 쿨타임·스타일 랭크·미니맵·보스 체력바)
- `menu.js` — 로고 인트로, 타이틀, 일시정지, 게임오버·클리어, 조작법, 설정
- `practice.js` — 콤보 연습장 (허수아비 배치·부활, 콤보 기록)
- `audio.js` — Web Audio API 효과음 합성 + 배경 음악 시퀀서 + 설정 저장
