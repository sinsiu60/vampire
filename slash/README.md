# Shadow Edge (가제)

2D 사이드뷰 핵앤슬래시 (DMC + 데드셀 느낌). 순수 HTML + JavaScript(Canvas), 외부 라이브러리 없음.

## 실행
`slash/index.html` 을 브라우저(Chrome/Edge/Firefox)로 열면 바로 실행. 서버 불필요.

## 진행 상황
- [x] 1단계: 이동 + 지상 콤보 + 근접 잡몹 + 타격감 (도형 임시 그래픽)
- [x] 2단계: 공중 콤보 (런처, 공중 3타, 내려찍기)
- [ ] 3단계: 실루엣 그래픽 + 애니메이션 + 이펙트
- [ ] 4단계: 패링 + 적 6종
- [ ] 5단계: 스타일 랭크
- [ ] 6단계: 던전 방 구조 + 미니맵
- [ ] 7단계: 보스
- [ ] 8단계: 무기 3종 + 스킬 + 루팅·인벤토리
- [ ] 9단계: 로고 인트로, 타이틀, UI, 사운드
- [ ] 10단계: 층별 테마·보스, 밸런스

## 조작 (2단계 기준)
| 키 | 동작 |
|---|---|
| A / D | 이동 |
| 스페이스 | 점프 (2단 점프, 길게 누르면 높이) |
| S + 스페이스 | 통과 발판 내려가기 |
| J | 약공격 4타 콤보 |
| K | 강공격 (길게 누르면 차지 Lv1 / Lv2) |
| J, J 후 K | 전진 찌르기 |
| S + K | 런처 (K 를 계속 누르면 같이 점프) |
| 공중 J | 공중 3타 콤보 (맞는 동안 체공) |
| 공중 K | 공중 날려베기 |
| 공중 S + K | 내려찍기 (적을 바닥에 꽂고 착지 충격파) |
| L | 대시 (무적 프레임, 공중 1회) |
| Esc | 일시정지 |
| R | 재시작 (게임오버/일시정지 시) |
| H | 히트박스 표시 (디버그) |
| F1 | 조작 도움말 숨기기 |

## 파일 구조 (`slash/js/`)
- `config.js` — **모든 밸런스 수치** (이동, 점프, 대시, 스태미나, 기술 프레임·데미지·히트박스, 적 능력치, 타격감)
- `main.js` — 60fps 고정 타임스텝 루프, 히트스톱, 카메라, 게임 상태
- `input.js` — 키 입력 (스텝 단위 pressed/released)
- `player.js` — 플레이어 상태머신 (이동/점프/대시/콤보/차지/피격)
- `enemy.js` — 적 AI (예고 → 공격 → 후딜, 경직·넉백)
- `combat.js` — 히트박스 판정, 데미지·크리티컬·넉백·히트스톱 처리
- `effects.js` — 파티클, 베기 궤적, 대시 잔상, 데미지 숫자, 화면 흔들림, 임팩트 프레임
- `render.js` — 배경(패럴랙스), 지형, 캐릭터 그리기
- `dungeon.js` — 지형과 충돌 (현재는 연습 아레나)
- `ui.js` — HUD, 일시정지/게임오버 화면
- `audio.js` — Web Audio API 효과음 합성
